# Unity-Übung – Ball und Schläger

**Movement.cs** liest die horizontale Eingabe und verschiebt den Schläger. **Ball.cs** verarbeitet Treffer, Punktestand und Neustart mit Rigidbody2D und TextMesh Pro. Die Skripte stammen aus Unity 2022.3.23f1. Für die Ausführung werden die Szene und ihre Inspector-Referenzen benötigt.
