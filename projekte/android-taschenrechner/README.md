# Android-Taschenrechner

Java-App mit einem bearbeitbaren Ausdrucksfeld, Zifferntasten und den vier Grundrechenarten. Die Auswertung übernimmt mXparser.

1. Den Projektordner in Android Studio öffnen. Der ursprüngliche Stand verwendet JDK 11, Android SDK 31 und Android Gradle Plugin 7.0.2.
2. mXparser 5.0.0 für JDK 11 separat beziehen und als **app/libs/MathParser.org-mXparser-v.5.0.0-jdk11.jar** ablegen.
3. Die App auf einem Emulator oder Android-Gerät ab API 21 starten.

Als kurzer Funktionstest kann **12+3** eingegeben und mit **=** ausgewertet werden. Erwartetes Ergebnis **15.0**.
